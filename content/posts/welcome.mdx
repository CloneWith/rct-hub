**Ranka's Chess Tournament** (**RCT**) 是 OFFC 系列的第三个比赛（更名），预计在今年9月正式开赛，限国内的 Open Rank 特殊规则比赛。本届翻新了下棋规则。

We're building the premier web platform for the osu! RCT tournament format —
manage rooms, build mappools, run the 4×4 board game, all with role-based access
control and real-time match state.

Stay tuned for more updates, and join our community to get the latest news!
